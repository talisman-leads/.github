# .github

The organization profile and the default community files for every repo in [talisman-leads](https://github.com/talisman-leads).

- [`profile/README.md`](profile/README.md): the page shown on [github.com/talisman-leads](https://github.com/talisman-leads)
- [`SECURITY.md`](SECURITY.md) and [`SUPPORT.md`](SUPPORT.md): shown on every repo that has none of its own

These files are generated from the live API documentation, so they always match the API.
