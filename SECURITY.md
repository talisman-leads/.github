# Security

Please report a security problem privately, never in a public issue or pull request.

How to report, what is in scope and how we credit researchers are in our [Vulnerability Disclosure Program](https://talismanleads.io/vulnerability-disclosure-program). The contact address is also in [security.txt](https://talismanleads.io/.well-known/security.txt).

If you think an API key of yours has been exposed, revoke it at once under [API keys](https://talismanleads.io/api-keys) and make a new one.
